
# TCP/IP Attack Lab

## Overview
Academic cybersecurity lab focused on understanding TCP/IP vulnerabilities and network attack techniques in a controlled virtual environment.

## Lab Exercises
- SYN Flooding and SYN Cookie protection
- TCP RST attacks on Telnet and SSH
- TCP RST attacks on video streaming
- TCP Session Hijacking
- Reverse Shell through TCP Session Hijacking

## Tools & Technologies
- Linux
- Wireshark
- Scapy
- Netwox
- Netcat
- TCP/IP

## Learning Outcomes
- Analyzed TCP packets and connection behavior.
- Practiced network attack simulations.
- Explored session hijacking and connection disruption.
- Examined SYN Cookies as a defensive mechanism.
